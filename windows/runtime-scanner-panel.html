Desde escáner

Escanea la factura y lee sus datos con OCR. Puedes añadir varias páginas de una misma factura y revisar los datos antes de guardarla.

Para escanear directamente, abre la edición de Windows y conecta el escáner con su controlador instalado. En la ventana de captura podrás elegir el dispositivo y sus opciones. Puedes repetir la captura para añadir páginas.

Escanea una página o carga las imágenes obtenidas con tu escáner. El reconocimiento OCR se realiza en este ordenador.

Hasta 10 páginas por factura. Desmarca la casilla para tratar cada imagen como una factura distinta. El PDF creado se adjuntará al guardar; conserva también tus documentos originales.
